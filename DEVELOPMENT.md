## 🔧 拡張・カスタマイズ

### センサの追加

センサの追加方法には「ユーザーセンサ」と「標準センサ」の 2 種類があります。  
**通常はユーザーセンサとして追加してください。**

| 種類           | 追加先                                                       | 用途                                                                       |
| -------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------- |
| ユーザーセンサ | `src/user/user_i2c_sensor.cpp`, `src/user/user_modbus_sensor.cpp` | 一般的なセンサの追加                                                  |
| 標準センサ     | `src/i2c/i2c_manager.cpp`, `src/modbus/modbus_manager.cpp`   | I2C マルチプレクサや 1-Wire to I2C ブリッジなど、特殊なデバイスの追加     |

| ドキュメント                                                                         | 内容                                     |
| ------------------------------------------------------------------------------------ | ---------------------------------------- |
| [I2C センサの追加方法（ユーザーセンサ）](./notes/HOW_TO_ADD_I2C_SENSOR.md)           | `user_i2c_sensor.cpp` への追加手順       |
| [I2C センサの追加方法（標準センサ）](./notes/HOW_TO_ADD_I2C_SENSOR_TO_MANAGER.md)    | `i2c_manager.cpp` への追加手順           |
| [Modbus センサの追加方法（ユーザーセンサ）](./notes/HOW_TO_ADD_MODBUS_SENSOR.md)     | `user_modbus_sensor.cpp` への追加手順    |
