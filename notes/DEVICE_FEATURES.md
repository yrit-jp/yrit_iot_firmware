### デフォルト設定値

すべての Modbus ポートで共通の設定値が使用されます。

| 設定項目   | デフォルト値 | 説明                                 |
| ---------- | :----------: | ------------------------------------ |
| BAUDRATE   |     9600     | ボーレート（bps）                    |
| DATA_BIT   |      8       | データビット長                       |
| PARITY     |      0       | パリティ（0: None, 1: Even, 2: Odd） |
| TIMEOUT_MS |     200      | 通信タイムアウト（ミリ秒）           |
| ID_MIN     |      1       | スキャンするユニット ID の最小値     |
| ID_MAX     |      5       | スキャンするユニット ID の最大値     |

## 📷 カメラ詳細

### M5Stack CoreS3

M5Stack CoreS3 は内蔵カメラをサポートしています。

| 項目       | 値              |
| ---------- | --------------- |
| 解像度     | VGA (640 x 480) |
| フォーマット | RGB565          |
| メモリ     | PSRAM 使用      |

設定項目:

| キー     | デフォルト値 | 説明                       |
| -------- | :----------: | -------------------------- |
| `ENABLE` |   `false`    | カメラを有効にするかどうか |

## 📝 補足情報

### 未実装 GPIO/Modbus デバイス

以下のデバイスは I2C のみサポートしており、GPIO および Modbus は未実装です。

- M5Stack Core2
- M5StickC Plus2
- M5Stack Atom S3
- M5Stack Atom S3R

### デバイス選定ガイド

| 用途                           | 推奨デバイス                      |
| ------------------------------ | --------------------------------- |
| 汎用 IoT センシング            | M5Stack Basic, ESP32 DevKit       |
| 複数 Modbus 機器との接続       | M5Stack Tough, M5Station          |
| カメラ画像取得                 | M5Stack CoreS3                    |
| コンパクトな設置               | M5StickC Plus, M5Stack Atom S3    |
| 有線 LAN 接続                  | M5Station, LilyGo T-Display S3 Pro |
| 多数の GPIO 入力が必要な場合   | ESP32 DevKit (6 ピン)             |
